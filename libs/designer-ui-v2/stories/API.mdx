# API and boundaries

This page documents data, helpers, contexts, hooks and types. They are **not UI
components** and do not receive invented component stories.

## Supported imports

```ts
import {
  ActionNodeCard,
  DesignerUiScope,
  defaultNodeStrings,
  getNodeGlyph,
} from '@microsoft/designer-ui-v2';
import type { NodeRunStatus, ActionNodeCardProps } from '@microsoft/designer-ui-v2';
import { nodeMetrics, nodeHoverCardTiming } from '@microsoft/designer-ui-v2/metrics';
```

The root exports the visual components, nonvisual APIs and types below.
`/metrics` is the React-free numeric data/timing entry; it does not re-export
components or hooks. `/package.json` exposes manifest metadata. Source/build
deep imports and a package `/nodes` subpath are unsupported. Storybook's exact
source aliases do not change the package export map.

### Glyph vocabulary

`NodeVisualKind` has exactly these keys: `http`, `response`, `schedule`, `delay`,
`compose`, `parseJson`, `variables`, `table`, `filterArray`, `join`, `dateTime`,
`inlineCode`, `terminate`, `invokeWorkflow`. Both constructors take public Fluent
icon props. See the [rendered pairs](?path=/story/icons-ificonregular--visual-kind-vocabulary).

```tsx
const glyph = getNodeGlyph('http');
<ActionNodeCard
  title="Send request"
  icon={<glyph.regular />}
  selectedIcon={<glyph.filled />}
  selected
/>;
```

### Helper composition

```ts
joinNodeSubtitle('Built-in', undefined, 'HTTP'); // "Built-in · HTTP"
getNodeStatusLabel('succeeded'); // "Succeeded"
toSafeExternalHref('/relative'); // undefined
toSafeExternalHref('https://example.com/docs'); // "https://example.com/docs"
```

### Localization example

```tsx
import { NodeInfoCard } from '@microsoft/designer-ui-v2';

<NodeInfoCard
  category="action"
  icon={null}
  title="Enviar solicitud"
  configured
  strings={{
    configured: 'Configurado',
    close: 'Cerrar',
    learnMore: 'Más información',
    opensInNewTab: '(se abre en una pestaña nueva)',
  }}
/>;
```

Function labels such as `tools.heading(count)`, `merge.label(name)` and
`collapse.show(count, noun)` / `hide(count, noun)` belong to the supplied
dictionary. Do not concatenate translated nouns into fixed English grammar.

## Deliberate host boundary

No XYFlow, Redux, React DnD, Query, routing, auth, backend, localization provider,
cloud or host services are required here. Decorative handles and DOM slot
markers are not connectable ports. A host owns operation normalization,
connector imagery/loading/failure, topology, mutations, execution, focus
navigation, dynamic measurements and clipping/portal placement.

Keep native modal `DialogSurface` on its normal modal portal; put scoped shared
presentation inside the dialog surface rather than mounting the modal into the
popover outlet. Cold native measurement/handle refresh, production adoption,
legal/publication and real-host validation gates remain unchanged.
