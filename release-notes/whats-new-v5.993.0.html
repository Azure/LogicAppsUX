What’s New in Azure Logic Apps v5.993.0

Highlights in this release:

  • Local JDBC connector now self-enables the Java multi-language worker when driver JARs are detected, with clear guidance if a JDK is missing. This makes local database connections work out-of-the-box in VS Code.
  • Improved security for agent chat iframes: stricter validation of messages and origins prevents untrusted embeddings from redirecting authenticated requests, while preserving same-origin and local dev behavior.

Thanks for using Azure Logic Apps.
