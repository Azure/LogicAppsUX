Whats New in Azure Logic Apps

This release includes improvements for developers using the Logic Apps extension for Visual Studio Code and stronger in-app security.

  • Visual Studio Code: The JDBC connector now works out of the box by automatically enabling the multi-language worker when needed, simplifying setup.
  • Embedded experiences: The in-app agent card now validates incoming messages and restricts trusted parent origins to prevent misuse.

Update your extension to benefit from these enhancements.
